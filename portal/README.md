# Modern careers frontend (server preview)

This directory is served at the root of the new Node service in MSOP/platform. Existing GitHub Pages root/join paths and the established Lark form workflow remain in place.

The homepage reads the existing jobs contract and renders source job descriptions as text. It does not post to Base or claim an application has been submitted. Referral and completion links keep their query parameters and enter the established join flow.

Backend and deployment instructions: `inetcoding/MSOP`, branch `server/hr-platform-20261018`, directory `platform`.
